# Prompt: Implement Feature

ศึกษา repository และเอกสารใน `docs/` ก่อน จากนั้นพัฒนา feature ที่ระบุโดย:

- ระบุของเดิมที่นำกลับมาใช้ได้
- อธิบาย domain model และ use case
- หลีกเลี่ยง logic ใน Widget
- เพิ่ม repository abstraction เมื่อมี persistence/integration
- เพิ่ม preview/confirmation/audit ตามความเสี่ยง
- เพิ่ม tests
- รัน format, analyze และ test
- สรุป changed files, compatibility impact และผลตรวจสอบ
