# Prompt: Review Change

ตรวจการเปลี่ยนแปลงเทียบกับ specification และ architecture โดยเน้น:

- Roster ยังเป็น Source of Truth หรือไม่
- มี duplicate implementation หรือไม่
- Business logic หลุดเข้า Widget หรือไม่
- Preview, confirmation และ audit log ครบหรือไม่
- Calendar sync รั่วข้อมูลบุคคลอื่นหรือไม่
- Responsive และ cross-platform impact
- Test coverage ของ logic สำคัญ
- Format, analyze และ test status

รายงานข้อค้นพบเรียงตามความรุนแรง พร้อมไฟล์และตำแหน่ง
