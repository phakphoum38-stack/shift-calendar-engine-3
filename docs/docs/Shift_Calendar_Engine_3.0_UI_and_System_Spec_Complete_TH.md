1. แนวคิดหลักของระบบ
======================================================================

ระบบใช้แนวคิดว่า “ตารางเวร” เป็นแหล่งข้อมูลหลักของระบบ

ลำดับการทำงานหลัก:

รายชื่อบุคลากร
→ สร้างตารางเวร
→ ตรวจสอบกฎและความขัดแย้ง
→ จัดการการแลกเวร
→ คำนวณเงินเวรและ OT
→ แสดงผลและพิมพ์ตาราง
→ ส่งเฉพาะเวรของผู้ใช้ไป Google Calendar
→ เก็บประวัติการทำงานและการซิงก์

ระบบต้องไม่ผูกกับโรงพยาบาลแห่งเดียว
ผู้ใช้สามารถแก้ไขชื่อเวร เวลา สี อัตราเงิน กฎ วันหยุด และปฏิทินได้จากหน้า Settings
โดยไม่จำเป็นต้องแก้ไขโค้ดหลัก

9. ระบบคิดเงินเวรและ OT
======================================================================

ระบบต้องตั้งค่าอัตราได้ ไม่เขียนค่าตายตัวในโค้ด

ประเภทการคำนวณ:

- อัตราคงที่ต่อเวร
- อัตราต่อชั่วโมง
- OT ต่อชั่วโมง
- On Call
- เวรวันหยุด
- ตัวคูณวันหยุด
- ตัวคูณกลางคืน
- ค่าเดินทาง
- ค่าเบี้ยเลี้ยง
- ค่าเสี่ยงภัย
- ค่าตอบแทนเฉพาะหน่วยงาน
- ค่าตอบแทนเฉพาะบุคคล
- หักเงิน
- เงินเพิ่มพิเศษ
- Custom Allowance

ตัวอย่างกฎ:

เวรบ่าย = อัตราคงที่
เวรดึก = อัตราคงที่
On Call = อัตราคงที่
OT = จำนวนชั่วโมง × อัตราต่อชั่วโมง
วันหยุด = อัตราเวร × ตัวคูณวันหยุด
เวรข้ามวัน = คำนวณตามกฎที่กำหนด
แลกเวร = เงินโอนไปยังผู้ทำเวรจริงหลังอนุมัติ

ลำดับความสำคัญของอัตรา:

1. อัตรา Override ในรายการเวร
2. อัตราเฉพาะบุคคล
3. อัตราเฉพาะหน่วยงาน
4. อัตราจาก Shift Template
5. อัตราเริ่มต้นของระบบ

ระบบต้องมี:

- Preview ก่อนคำนวณจริง
- รายละเอียดสูตร
- แยกเงินแต่ละประเภท
- รองรับการแก้ไขด้วยสิทธิ์
- Audit Log
- Lock งวดที่ปิดแล้ว
- เปิดงวดใหม่
- Export รายงาน
