# Shift Calendar Engine 3.0 — Release Notes

## สถานะ
เอกสารนี้เป็นแม่แบบสำหรับ release notes ของรุ่น 3.0

## Highlights
- ระบบตารางเวรแบบ configurable
- Responsive UI บน Flutter หลายแพลตฟอร์ม
- Employee Directory และ Shift Templates
- ตารางรายเดือนและ A4 print/export
- Rule, Conflict, Policy และ Preview engines
- Shift exchange และ approval workflow
- Payroll, OT และ allowance rules
- Google Sheets import และ Google Calendar sync แบบปลอดภัย
- Workspace, profiles, audit history และ backup

## ก่อนออก Release
- format/analyze/test ผ่าน
- ตรวจ migration และ backward compatibility
- ทดสอบ import/export และ restore
- ทดสอบว่า Calendar ส่งเฉพาะเวรของผู้ใช้
- ตรวจ security และ secret handling
- ทดสอบ platform builds ที่รองรับ
