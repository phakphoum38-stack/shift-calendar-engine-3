# Support

Shift Calendar Engine is maintained as an open-source project.

## Getting help

Before opening a request:

1. Read the README and project documentation.
2. Search existing issues and pull requests.
3. Confirm the problem still occurs on the latest `main` branch.
4. Remove secrets, credentials, patient information, and personal roster data from logs or screenshots.

Use GitHub Issues for reproducible bugs and feature requests. Include the platform, Flutter version, steps to reproduce, expected behavior, actual behavior, and relevant sanitized logs.

Security vulnerabilities must be reported privately according to `SECURITY.md`, not through a public issue.

Support is provided on a best-effort basis. No response-time or service-level guarantee is provided.
